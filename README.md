## Projects I built on my own

- [Site assistant](https://github.com/hamimabbu/site-assistant): a small chat assistant any site can add. It answers from written facts and says so when something is not there. Questions are filtered, every answer is checked against the facts before it is shown, each visitor is rate limited and the keys stay in server settings. Plain JavaScript and serverless functions, no framework and no dependencies. A script that throws 100 attack inputs at it finds no leaks. This is the assistant that runs on my portfolio.
- [Portfolio](https://github.com/hamimabbu/portfolio): the source of my portfolio site, with the assistant set up for me, a contact form that mails me without showing my address, and a one-page CV.
- [LayerLens](https://github.com/hamimabbu/layerlens): a small Node.js web app that shows a visitor what their browser and connection reveal, and where each detail came from. A request cannot name a target, public-record lookups run only after the operator turns a source on and the visitor agrees, and a written threat model lists nine risks with the control for each. 62 automated tests run on Node.js 22 and 24 in GitHub Actions. It is not deployed.
- [Active Directory home lab](https://github.com/hamimabbu/active-directory-home-lab): a VirtualBox domain with a Windows Server 2022 domain controller and a Windows 11 client joined to it. The attacks come next (LLMNR poisoning, SMB relay and Kerberoasting), and I will write up what each one leaves in the logs.
